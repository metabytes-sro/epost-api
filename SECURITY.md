# Security Policy

## Supported versions

| Version | PHP        | Supported          |
|---------|------------|--------------------|
| 1.x     | 8.1 – 8.5  | Yes                |
| 0.x     | 7.x        | No, please upgrade |

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security problems.

Email [info@metabytes.eu](mailto:info@metabytes.eu) with a description of the
issue, the affected version, and steps to reproduce if you have them. You will
receive an acknowledgement within five working days. Once the problem is
confirmed we will work on a fix, release it as a patch version, and credit you
in the changelog unless you prefer otherwise.

## Scope

This package is a thin client for the E-POSTBUSINESS API. Vulnerabilities in
the API itself should be reported to Deutsche Post through their own support
channels.
